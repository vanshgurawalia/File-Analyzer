# File Analyzer 🗂️

A C++ project that analyzes `.txt` files to provide useful statistics such as:

- Number of lines
- Number of words
- Number of characters
- Frequency of each word
- Most common word

## 💡 Features

- Reads from a `.txt` file
- Displays stats in a clean format
- Handles empty or unreadable files
- Word frequency analysis

## 📁 How to Run

1. Compile the code:

   ```bash
   g++ main.cpp file_reader.cpp analyzer.cpp -o FileAnalyzer.exe
   Run the executable:

2. Run the executable:
./FileAnalyzer.exe
Enter the name of the .txt file you want to analyze (make sure it exists in the same folder).
